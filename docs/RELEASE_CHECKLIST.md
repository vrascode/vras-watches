# Checklist de publicacao

## Antes de publicar
- Confirmar identificacao do produto.
- Confirmar variante.
- Validar fotografias autorizadas.
- Confirmar preco.
- Confirmar disponibilidade.
- Executar testes.

## Git
- Revisar alteracoes.
- Criar commit significativo.
- Publicar na branch main.
- Conferir sincronizacao com GitHub.
