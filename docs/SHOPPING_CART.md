# Carrinho de compras

## Operacoes
- Adicionar produtos disponiveis.
- Atualizar quantidades.
- Remover produtos.
- Calcular subtotais.

## Migracao
Produtos antigos incompatíveis devem ser removidos
do carrinho com aviso adequado.

## Consistencia
Preco e variante devem corresponder ao produto selecionado.
