# Importacao de midias

## Fluxo
1. Receber arquivos autorizados.
2. Identificar modelo e variante.
3. Preparar o manifesto.
4. Executar o importador.
5. Validar arquivos gerados.
6. Conferir a galeria no navegador.

## Seguranca
Arquivos sem correspondencia comprovada nao devem
ser vinculados automaticamente aos produtos.
